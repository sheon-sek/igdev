# igdev 0.2.0

The first release since 0.1.2 (2026-09-23), with the same code as 0.1.3. It is numbered
as a minor release because it removes commands and changes defaults. It carries the whole
refactor: CLI Contract 2, lookup, running-Gateway operations, open development defaults,
`igdev cleanup`, and the rewritten Agent Skill.

Install or upgrade:

```sh
curl -fsSL https://github.com/sheon-sek/igdev/releases/latest/download/install.sh | bash
```

## Read this before upgrading

- **CLI Contract 2 (ADR 0010).** `gateway smoke`, `verify`, `module scan` and
  `module cache-path` are removed with no deprecation release. Use `gateway wait --smoke`,
  `check --all [--gateway]`, and `igdev check` instead. `agent context --json` no longer has
  `commands.verify`. A checkout set up under Contract 1 is refreshed by the next command.
- **`[commands].smoke` is retired.** `init --command-smoke` is an unknown flag; an existing
  contract that states it still loads.
- **New defaults (Phase 9).** Modules default to all of the image's built-in modules, with a
  "selected/custom only" mode; `allow_unsigned_modules` defaults to true.
- **Open by default (ADR 0012).** Guards that only protected the disposable Gateway are gone.
  The EULA is still a person's acceptance, once per machine, and now gates only the verbs that
  start a Gateway (`IGDEV_ACCEPT_EULA=Y` gives it for an environment). `IGDEV_E_CAPACITY` is
  retired; low memory is a warning.

## New

- `igdev lookup` finds a `system.*` function or a Gateway REST endpoint from one sentence.
- `igdev restart`, `igdev module install <file.modl>`, `igdev build --install` and
  `igdev project import|export` work on the running Gateway and keep its data (ADR 0011).
  A quarantined module is the new `IGDEV_E_MODULE_QUARANTINED`.
- `igdev cleanup` removes what igdev created: the checkout's Instance and `.igdev/`, then
  `--deinit`, `--machine` and `--uninstall` scopes (ADR 0013). The last two need `--yes`.
- `igdev gateway api` calls the Gateway REST API with the Instance's own token.
- `igdev gateway exec` and `gateway data put|get` reach inside the Gateway container; `data`
  now reaches any container path.
- `igdev gateway ensure` leaves a running, healthy Gateway, reusing one when it can.
- `igdev gateway trial` and `gateway trial reset`; with `trial_reset = "auto"` a
  `trial-keeper` service resets an expired trial in place (ADR 0008).
- Each Instance is seeded with an API token (ADR 0007), and `[gateway] seed` merges tracked
  configuration into a fresh Gateway (ADR 0009).
- `igdev ci-local` runs one workflow locally through act, `--with-gateway` included, and
  fetches a pinned act when none is installed.

## Changed and fixed

- The Gateway keeps the image's built-in modules and can reach the host.
- A missing or stale Checkout Setup is refreshed by the Gate instead of stopping the command.
- `gateway credentials` prints the credentials in human mode; `gateway api` streams whole
  bodies and accepts request bodies up to 1 GiB.
- The Agent Skill is rewritten around three layers (environment, operations on the Gateway, knowledge and checks) and three
  scenarios: SDK modules, MCP Tools, and AI Agents.
- The seed names the real login provider, and Baselines restore again.
- Lifecycle verbs report progress instead of hanging silently; staged modules load, and
  `gateway wait` means ready.
